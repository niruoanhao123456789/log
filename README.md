# Log

#### Introduction

This project is a synchronous and asynchronous logging system.

Its main supported features are as follows:
1. Support for multiple log message levels.
2. Support for both synchronous logging and asynchronous logging.
3. Support for reliable writing of logs to the console, specified files, and rolling files.
4. Support for concurrent log writing in multithreaded programs.
5. Support for extending different log destination targets.
