# Log

#### 介绍

本项目为同步与异步日志系统

其主要支持以下功能:
1、支持多级别日志消息
2、支持同步日志和异步日志
3、支持可靠写入日志到控制台、指定文件以及滚动文件中
4、支持多线程程序并发写日志
5、支持扩展不同的日志落地目标地
