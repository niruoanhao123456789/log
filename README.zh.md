# Log

#### 介绍

本项目为同步与异步日志系统

其主要支持以下功能:
1.  支持多级别日志消息
2.  支持同步日志和异步日志
3.  支持可靠写入日志到控制台、指定文件以及滚动文件中
4.  支持多线程程序并发写日志
5.  支持扩展不同的日志落地目标地

#### 核心技术

1.  类层次设计(继承和多态的应用) 
2.  C++11(多线程、auto、智能指针、右值引用等) 
3.  双缓冲区
4.  ⽣产消费模型
5.  多线程
6.  设计模式(单例、工厂、代理、建造者等)


#### 环境搭建

本项目不依赖其他任何第三⽅库， 只需要安装好CentOS/Ubuntu + vscode/vim环境即可开发。
